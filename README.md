### 🚀 Proyectos Destacados

* **[Weather Dashboard & Analytics](https://github.com/RoyDeveloper23)**  
  Aplicación web reactiva para visualización y filtrado dinámico de datos meteorológicos.  
  *Stack:* `React` · `TypeScript` · `Material UI` · `Vite` · `Open-Meteo API`

* **[Clasificador-Tumores-PCA-ML](https://github.com/RoyDeveloper23/Clasificador-Tumores-PCA-ML)**  
  Modelo de Machine Learning para detección de anomalías celulares y diagnóstico oncológico aplicando reducción de dimensionalidad con PCA/SVD y árboles de decisión.  
  *Stack:* `Python` · `Scikit-Learn` · `NumPy` · `Pandas` · `Matplotlib`

* **[WORKSIM Platform](https://github.com/RoyDeveloper23)**  
  Prototipo de entorno simulador para evaluación técnica y auditoría de código asistida por IA sin sesgos ni respuestas condescendientes.  
  *Stack:* `Next.js` · `TypeScript` · `Supabase` · `Tailwind CSS`
